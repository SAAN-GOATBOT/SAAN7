🧭 Help System

The bot includes a paginated command browser to keep the help message clean even with hundreds of commands.

/help

Shows the first page of available commands.

/help 2

Shows the second page.

/help 10

Shows the final page when the command library contains 300+ commands.

For individual command information:

/help dice
/help quiz
/help spin
/help bank

Each command can display its description, aliases, version, permission, cooldown, author and usage.

⚙️ Command Structure

Commands are organized as independent modules inside:

scripts/
└── cmds/
    ├── 4k.js
    ├── ai.js
    ├── bank.js
    ├── dice.js
    ├── help.js
    ├── quiz.js
    ├── spin.js
    ├── wheel.js
    └── ... 325+ commands

This makes it easy to add, replace or customize individual commands without rebuilding the entire command system.
